# Changelog

All notable changes to GASCII are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.1] - 2026-08-06

### Added

- Prebuilt binaries for ARM64 Linux (Raspberry Pi and other aarch64 devices)

## [0.1.0] - 2026-08-05

Initial beta release.

### Added

- ASCII canvas editor with drawing tools, brushes, and keyboard chords
- Layers with visibility toggles and reordering
- Frame-by-frame animation: preview, drag-to-reorder, keyboard commands, export
- Plugin system with a plugin manager; density brush, animation pane, and layers
  panel ship as plugins
- Windows pen/stylus support including barrel-button handling
- PNG export and image-reference backgrounds
- Fullscreen kiosk mode (`--fullscreen`)
